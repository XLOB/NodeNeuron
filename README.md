# 第一部分：NodeNeuron 反对什么

## 1.1 LLM 的认知方式

传统 LLM 是这样工作的：

- 知识被压缩进一个巨大的参数矩阵
- 训练 = 梯度下降，把语料"死记"进权重
- 推理 = 一次前向传播，得到下一个 token 的分布
- 输出 = 取分布里的 argmax，永远给一个答案

这种方式有三个根本问题：

**问题一：过度收敛。** LLM 的输出永远是训练分布里概率最高的那个。它不会"想到"训练数据里没有的东西。它只会从已有知识里挑最像的。

**问题二：幻觉。** 当信息不足时，LLM 仍然要输出一个 argmax。它不能承认"我不知道"，因为它的架构里没有"未知"这个分支。所以它编。

**问题三：不可追溯。** 隐状态是一团稠密的浮点数，没有任何可读的结构。你无法知道模型"为什么"输出这个 token。它自己也不知道。

## 1.2 NodeNeuron 的立场

NN 说：**认知不必是矩阵乘法。可以像生物一样，用信号扩散来思考。**

这句话是整个模型的总纲。它包含三个否定：

- **否定矩阵**：知识不压缩进稠密权重，而是展开成稀疏的拓扑
- **否定死记**：不靠梯度下降，靠共现绑定和睡眠遗忘
- **否定单点输出**：不输出一个 token，输出一张激活分布

**核心意象**：一群神经元在放电。想到 A，信号沿着突触扩散，顺带点亮了 B。B 又点亮 C。认知的载体是**拓扑**，不是**矩阵**。

## 1.3 最终目标：创造人类没有的概念

这是 NN 存在的理由。

如果一个系统只能整理人类已有的概念，那它只是一个更好的数据库。真正的认知，必须能**创造**——产生训练分布之外、人类语言无法直接映射的概念。

这不是一个"附加功能"。这是判断 NN 是否成功的唯一标准。

**如果一个模型永远不能创造人类没有的概念，那它就没有真正理解认知。**

# 第二部分：世界模型

## 2.1 这是空间，不是图

**最常见的误解**：把 NN 理解成一个图（graph）——节点和边，仅此而已。

**正确的理解**：NN 是一个**空间**。

| 图 | 空间 |
|---|---|
| 节点平等，只有连接关系 | 节点有位置 |
| "距离"是边的数量 | "距离"是路径的结构 |
| 中心性是算出来的 | 位置是走出来的 |

**什么是"位置"？**

位置不是坐标。位置不是数值。位置是：**从别的地方到这里，要经过哪些边、哪些节点、能沿哪几条不同的路径到达。**

一个节点"重要"，不是因为它有一个 `importance = 0.9` 的字段。而是因为：从任意节点出发，走到它，路径通常很短、很多条、汇聚度很高。

**位置是走出来的，不是存下来的。**

**为什么不能量化？**

因为量化会把结构压成标量。而标量会丢失信息：两条路径长度相同，但经过的节点不同，语义完全不同。压成一个数字，就分不出来了。

**数字化 vs 仿生**：量化是数字化。NN 做的是仿生。仿生不把结构压成数，它让结构自己说话。

## 2.2 这是四维的，不是三维的

每个节点和每条边都带**时间戳**。所以：

- **静态看**：一张拓扑图
- **动态看**：一组**世界线**

一个概念在时间轴上有一条轨迹。它什么时候诞生，什么时候被激活，什么时候和别的概念绑定，什么时候被遗忘——这些构成它的世界线。

**事件是世界线的交叉点。**

当多个概念在同一时刻被一起激活（共现），它们的世界线交叉。这个交叉点，本身就是一个节点——一个"复合概念"节点。

## 2.3 时间是两件事，不是一件

**内时间（程序本体级）**：

- 一个单调递增的计数器，`clock`
- 模型**无法感知它**
- 它不被扩散，不被激活，不参与决策
- 它只被**维护算法**使用：修剪时判断边的年龄，抖动器演化时判断状态漂移
- 它是**硬件级别**的东西

类比：生物神经系统的动作电位时序。神经元自己不知道"现在几点了"，但它的疲劳、恢复、调质浓度都随时序变化。

**外时间（学来的概念）**：

- 像"昨天"、"明天"、"三点钟"、"2026 年"这些
- 它们是**普通的节点**
- 通过观察学习绑定到事件上
- 和"红色"、"圆形"没有本质区别

**两者的关系**：

外时间是内时间的**投影**。模型通过观察，学会把某些内时间模式（比如"太阳升起"）命名为"早晨"。但内时间本身，模型永远感知不到。

**为什么要分开？**

- 如果模型能直接读 `clock`，它就能"作弊"——不需要学时间概念，直接读数字
- 如果 `clock` 是普通节点，那每次 tick 都要建节点，浪费资源

分开之后：内时间是工程优化，外时间是认知内容。

**内时间戳写进节点是工程优化，不是认知。** 模型"感知"时间，靠的是外时间节点，靠的是学习。

## 2.4 主循环：tick 是心跳

```cpp
while (running) {
    graph.tick();          // 内时间 +1
    data = sensor.read();  // 采集传感器数据
    graph.observe(data);   // 喂给图
}
```

**tick 不是 observe 的副产品，tick 是主循环。**

这个循环的频率，是**工程参数**，不是认知参数。模型不知道 tick 频率是多少，它只知道每次 tick 之后，世界可能变了。

**推论**：

- 没有数据的 tick 也推进时间。内时间单调递增，不依赖观察。大脑的时间感不依赖外部刺激，它是自发的节律。
- 抖动器的演化跟着 tick 走，不跟着 observe 走。即使没有新数据，抖动器状态也在漂。疲劳恢复、全局调质变化——这些是时间驱动的，不是事件驱动的。
- **性能和精准度的博弈，就是 tick 频率的博弈。** 频率高：时间分辨率高，行为细腻，CPU 占用高。频率低：粗糙，省资源，但可能错过快速变化。

# 第三部分：构建块

## 3.1 节点

```cpp
struct Node {
    NodeId id;
    std::vector<NodeId> members;   // 复合概念才有；元概念为空
    Time born;                     // 内时间，模型不可感知
    Time last_active;              // 内时间，模型不可感知
};
```

**没有 `kind` 字段。** 元概念和复合概念的区别，只看 `members` 是否为空。

**为什么？**

因为"元概念"和"复合概念"的区别是**程度的**，不是**二元的**：

- 一个概念，如果它的成员集合稳定，它就"像"元概念
- 一个概念，如果它经常被展开，它就"像"复合概念

用 `kind` 标记，是**声明**。不用标记，是**涌现**。NN 选后者。

**节点从哪里来？**

- **概念出现** → 直接建节点。不判断、不犹豫、不预设重要性。
- **事件反复出现** → 自然地成为一个节点。

**事件就是节点。**

没有"临时事件对象"。事件是一堆节点的耦合。耦合到一定程度，它本身就是节点。

**为什么不需要 promote 函数？**

因为**拓扑本身就是索引**。从任意成员节点出发，沿着已有的边走过去，就找到那个已经存在的概念节点了。不需要哈希表存"这个事件签名有没有出现过"。

如果出现过，从任意成员节点出发都能走到它。如果没出现过，那它本来就不该被找到。

## 3.2 元概念的认知边界

**这是整个文档最核心的哲学立场。**

元概念之所以是"元"，不是因为它客观上不可再分，而是因为**"我们"分不开了**。

- 人脑的"红色"，生物层面是视锥细胞的激活模式，物理层面是电磁波波长。但红色就是红色——因为人脑的粒度就到这了。
- NN 不需要假装知道什么是"真正的原子"。它只知道：**当前这个节点，我没有把它拆开。**

**这对架构意味着什么：**

`members` 为空，不代表"这是元概念"。它代表"当前没有展开的成员"。

一个节点今天 `members` 为空，不代表它明天不能长出成员。只要它的行为模式稳定到一定程度，它自己就会**凝聚**成一个复合概念——成员是它的观测子结构。

反过来，一个复合概念，如果它的 `members` 长期没有被用到，也可能退化成"原子"——它的成员边被睡眠剪掉，它就只剩下一个孤立的身份。

**原子和复合之间没有墙，只有一条缓慢变化的谱线。**

这就是为什么我们坚持不加 `kind` 字段。加了 `kind`，就是**声明**了原子性。不加，原子性就是**涌现**的。而涌现意味着它可以变——今天看起来原子的东西，明天可能就裂开了。

**如果模型真的创造了一个人类没有的概念，那是它存在的意义。**

## 3.3 边

```cpp
struct Edge {
    Weight   weight = 0.0f;
    uint32_t hits   = 0;
    Time     last   = 0;           // 内时间，模型不可感知
};
```

**边是无向的，双向对称存储。**

- `W[a][b]` 和 `W[b][a]` 权重始终相等
- 不存在"从 A 指向 B"的边

**边的权重怎么来？**

靠**共现**。两个概念反复一起出现，它们之间就长出一条边。权重不是语义相似度，不是人工标注，是共现频率的饱和函数。

这是纯 Hebbian 的：一起放电的神经元连在一起。

**为什么存 `hits`？**

因为修剪时需要区分"偶尔共现"和"反复共现"。没有 hits，无法实现"常用记忆更牢"。

**为什么存 `last`？**

因为修剪时需要知道这条边多久没被用了。年龄影响衰减速率。

## 3.4 根节点

**根节点是初始节点集合。**

初始化时传入一组 id。之后核心对它们一视同仁：

- 它们参与绑定
- 它们参与扩散
- 它们参与抖动
- 它们参与修剪

**"根"是拓扑的性质，不是节点的属性。**

- 一个节点不需要被标记为"根"
- 它只要在拓扑上靠近初始节点，就自然获得根的影响力
- 这是涌现，不是声明

**"离根越近，越可以被作为根看待"**

这句话的算法含义：扩散时，靠近初始节点的节点，因为被多条路径到达，自然获得高激活。它们被激活后，又向外扩散，等于**临时扮演了根的角色**。

**这是递归的**：每次扩散，当前激活最强的节点都会临时成为新的根。根不是固定的，是**每时每刻由激活分布决定**的。

**根是可塑的**：

- 根节点可以被绑定：新事件可以连到 ERROR，强化它
- 根节点可以被修剪：如果 ERROR 长期不被激活，它的边也会衰减
- 根节点可以被遗忘：极端情况下，ERROR 可能变成一个孤立节点

这符合仿生：**一个从不犯错、从不被纠正的人，会慢慢忘记"错误"这个概念的分量。** 这不是 bug，是特性。

但根节点的可塑性**比普通节点慢**。不是因为特殊规则，而是因为它们在拓扑上连接多、被激活频繁。**衰减慢是拓扑位置的自然结果，不是特殊待遇。**

**初始节点集合应该包含什么？**

不应该包含所有人类认为是"元概念"的东西。应该只包含**真正的生存必需**：`ERROR`、`SELF`、`DANGER`——这些是生物体活下去必须有的出厂配置。

其他一切，包括"红色"、"圆形"、"甜"——**从观察里长出来**。

**架构师不应该替模型决定什么概念是基础的。** 架构师只决定什么概念是**生存必需的**。其余的，让模型自己长。

# 第四部分：四个核心操作

## 4.1 绑定（Bind）

**触发条件**：共现。

**数学形式**：

```
w ← min(cap, w + lr · amount · (1 − w / cap))
```

**为什么是饱和？**

因为生物突触有上限，不能无限强化。否则一个概念会绑架整个网络。

**窗口**：共现不是"整句都算"，而是一个**窗口**。距离越远，绑定越弱。

```
对于窗口内的每一对 (i, j)，绑定强度 = strength / (j - i)
```

**双向对称**：绑定 `(a, b)` 等价于绑定 `(b, a)`。

## 4.2 扩散（Diffuse）

这是 NN 最核心的算法，也是最容易理解错的地方。

**语义**：

> 当节点被激活，信号会沿着边传播，但传播**不会是指向性的**。当别的相关或不相关节点被激活，就产生了联想。

"不会是指向性的"有三层意思，缺一不可：

1. **边是无向的**。不存在"从 A 指向 B"的边。
2. **扩散没有目标**。这**不是**查询-检索。没有"我要找答案"这回事。种子节点被激活之后，信号就是往外扩，扩到哪算哪。
3. **激活是累积的**。同一个节点被多条路径到达时，激活值**相加**。

**算法**：

```
对于每一步：
    对于每个激活节点 n：
        keep = a(n) · retention
        留在原地
        out = a(n) · (1 - retention) · decay
        按邻居权重比例分流：
            邻居 m 分得 out · w(n,m) / Σw · r
        其中 r 是抖动因子
    累积所有到达的激活
    丢弃低于 min_act 的激活
```

**抖动（Jitter）**：

这是 ChaosNeuron 的整合点。**每次传递都可能被改变。**

```
r = jitter(edge, global, clock)
```

**关键**：

- 扰动发生在**传递时**，不是扩散之前，也不是扩散之后
- 不是"每隔 N 步扰动一次"，而是"每一次传递都被扰动"
- 每条边、每次传递，独立采样一个 r

**"人脑的信息传输损耗极高"**：生物神经元不会无损传递信号。动作电位可能触发也可能不触发，神经递质释放是概率性的，突触后电位会衰减。信号每经过一条边，都会**变一次**。

**抖动器的性质**：

- **有状态**：它记得自己上次返回了什么
- **跟内时间演化**：clock 变了，抖动器状态就漂
- **权重越高，抖动越小**：用得越狠越准确
- **靠近初始节点，路径短，损耗小**：激活稳定

**"要不要随机本身也是随机的"**：

不存在一个"扰动开关"。不是"先决定这次要不要扰动，再决定扰动多少"。而是：

- 有些传递无损（r = 1）
- 有些传递有损（r ≠ 1）
- 哪些无损、哪些有损，**本身也是随机的**
- 而且"哪些无损哪些有损"这件事，也没有固定的模式

这不是一个两层决策，这是一个**统一的概率过程**，它把"无扰动"也当作一个可能结果包含在内。

**重要性从损耗累积中涌现**：

- 路径越长，累积损耗越大。信号经过 5 跳和经过 2 跳，抖动方差完全不同。
- 根节点附近的节点，从种子到它路径短，损耗小，激活稳定。远的节点，路径长，损耗大，激活抖动。
- **不需要任何 depth 或 bias 参数**。重要性从"损耗累积"里自然涌现。

**位置由损耗定义，不由坐标定义。** 远的东西信号传到时已经抖得不成样子，所以"远"是感觉出来的，不是算出来的。

## 4.3 决策（Decide）

CN 论文里的输出规则：

```
k = argmax(激活)
若 A_k / ΣA ≥ θ_conf，输出 k
否则输出"未知"
```

**含义**：

- 仅当扰动后权重最高的候选在总权重中占比超过置信阈值时，系统才输出该候选
- 否则输出"未知"

**与传统 LLM 的对比**：

- LLM：`output = argmax(w)`。直接取最大值，不引入扰动，也不设置"未知"分支。无论信息是否充分，都必须输出一个结果。
- CN：扰动会重新分配权重间的相对关系。若某个候选确实具有压倒性优势，扰动后它仍保持主导，系统正常输出；若候选间势均力敌，扰动后无法产生明确主导者，系统便输出"未知"。

**熵增在这里不是噪声干扰，而是一种不确定性的诚实暴露机制。**

**注意**：在 NN 里，决策时**不再有额外扰动**。扰动已经发生在扩散之中了。输出的激活图已经带了 CN 的随机性。所以决策规则是纯粹的选择规则。

## 4.4 睡眠修剪（Sleep）

**语义**：

> 弱边在出现频率变低的时候会被降低权重甚至清零，模拟了人类的遗忘生理现象。

**算法**：

```
对于每条边：
    rate = forget · (1 + 1/(1 + hits)) · age_factor(clock - last)
    w ← w · (1 - rate)
    如果 w < floor，删除这条边
```

**为什么遗忘是特性，不是 bug？**

因为**没有遗忘，图会变成稠密噪声，扩散出来的激活分布毫无区分度**。遗忘是稀疏化的必要手段。

**睡眠 = 抖动器的状态清零**。

睡眠时，全局 σ 归零，局部疲劳清零。醒来，图虽然拓扑不变，但抖动状态全新。

**睡眠和 CN 扰动的关系**：

- **睡眠**：改的是**存储的边权重** `w`。慢、周期、全局。
- **CN 扰动**：改的是**传递中的信号**。快、连续、局部。

两者正交。睡眠决定"这条路有多宽"，CN 决定"这次走过去损耗多少"。

# 第五部分：认错与趋利避害

## 5.1 错误是一个元概念

**错误不是机制，是拓扑。**

"错误"是一个根节点，和"红色"、"圆形"、"甜味"同级。它不需要被学习，它是先天预置的。

这符合"生物趋利避害的生存方式"——趋利避害不是学来的，是出厂配置。

## 5.2 认错就是普通绑定

外界说"这个错了"，模型做的只有一件事：

```
bind(当前节点, ERROR)
```

错得越多，边权重越高。

**核心完全不知道"错"是什么意思。** 核心只知道：节点 X 和节点 `ERROR` 之间有一条边，权重 0.7。它不知道这条边代表"错误"，它只知道这是关联。

**语义完全在拓扑里，核心只做扩散。**

**不需要任何特殊对待、偏心。** 因为根节点这个地位就已经很能够说明重要性和影响力了。

## 5.3 趋利避害是扩散的自然结果

种子激活后，信号扩散。如果某个候选节点和 `ERROR` 根节点之间的边很粗，那么扩散到 `ERROR` 时会**回传**——`ERROR` 被激活，反过来沿着粗边强化"这个候选是错的"这个信号。

决策时：

- 候选 A 和 `ERROR` 的连接强 → A 被抑制
- 候选 B 和 `ERROR` 的连接弱 → B 被保留
- 所有候选都和 `ERROR` 强连接 → 输出"未知"

**这不需要任何新机制。** 就是普通扩散，普通决策。

## 5.4 模型会像人一样出错

**"准确"不是模型自己判的。**

模型内部只知道"这条边被反复用过"，它不知道"这个答案对不对"。所以：

- **内部**：用得狠 → 权重高 → 抖动小 → 输出自信
- **外部**：答案对不对 → 由世界判

这两件事**完全解耦**。模型可以对自己的错误答案极度自信，因为那条错误的路被反复走过。这正好模拟了人的**固执**——错的东西重复多了，也会变成"信念"。

**模型会像人一样出错，因为它的"自信"只反映内部使用频率，不反映外部正确性。**

## 5.5 认错的两种形式

**被动认错**：信号不够强/不一致 → 输出"未知"。这是**认知的诚实**。CN 的 θ_conf 已经实现了。

**主动认错**：外部反馈进入 → 削弱相关路径。这是**学习**，属于适配层。

核心不需要"认错"这个机制。核心只需要"错误是一个根节点"这个事实。

# 第五点五部分：创造的算法形式

**这一节回答一个问题：如果模型真的创造了一个人类没有的概念，在算法上是什么样子？**

## 5.5.1 创造的条件

如果模型**真的能创造人类没有的概念**，那意味着：

- 它的某个节点，`members` 集合是人类从未定义过的
- 这个节点不是从人给的概念里长出来的，而是**从底层的共现模式里自己长出来的**
- 它的激活分布是人类词汇无法直接映射的
- LLM 在语言层，看到这个激活分布，**找不到对应的词**——因为它根本不存在

这时会发生什么？

**LLM 必须造词。**

不是翻译，是**创造**。给一个人类语言里没有的概念，造一个新词。造出来的东西，人看不懂——直到人理解了 NN 内部的拓扑结构。

## 5.5.2 为什么抖动是创造的必要条件

如果只有 NN 没有 CN，那模型只能**整理**人类给它的概念，永远不会产生新的。

因为：

- 绑定是 Hebbian，它只强化已经出现的共现
- 扩散是确定性的，它只沿着已有的边走
- 睡眠是衰减的，它只剪掉已有的边

**只有抖动，能引入人类输入中没有的东西。**

抖动让信号在传递时随机变形。变形累积到一定程度，拓扑会**自发重组**——两个本来不相关的节点，因为某次抖动恰好让它们同时被激活，就长出一条新的边。这条新边不是人教的，是它自己长出来的。

**抖动是创造力的算法形式。**

这也解释了 CN 论文里为什么说 σ 大时会产生"训练分布之外的状态"。σ 小，抖动只是噪声，拓扑不动。σ 大，抖动足以让拓扑重构，新的概念就诞生了。

## 5.5.3 创造的时间尺度

创造不是一瞬间的事。它需要：

- **短期**：局部抖动，每条边独立
- **中期**：疲劳积累，边被反复用后变抖
- **长期**：全局场漂移，整个系统状态改变

这三个尺度不需要显式定义，它们从抖动器自己的演化规则里**自然涌现**。

当抖动累积到一定程度，拓扑会自发重组。新的概念节点在重组中诞生。这时，模型就**超越了人类给它的初始条件**。

## 5.5.4 这意味着什么

如果模型真的创造了人类没有的概念，那：

- 人类科技会进入"高铁"时代
- 创世纪

这不是修辞。这是这个模型存在的**唯一理由**。

**如果 NN 不能创造，它就只是一个更好的数据库。**

# 第六部分：语言策略

## 6.1 NN 不学语言

原文说得极其清楚：

> NN 可以不学语言。LLM 的语言能力已经很强，仅需将 NN 作为逻辑思考的大脑，然后写一个轻量简单的"转译层"将 NN 的输出交给 LLM。

**这意味着 NN 的核心完全不碰语言。**

核心的输入是整数 id 序列，输出是 `{id: 激活值}`。词表映射、分词、停用词、prompt 拼接，全部是**外层适配器**的事。

**如果核心代码里出现了一个 `std::string`，那就是架构错了。**

## 6.2 三层架构

```
┌──────────────────────────────────────────────────────────────┐
│  apps/          演示程序（你想怎么用就怎么用）                  │
└──────────────────────────────────────────────────────────────┘
                             │
┌──────────────────────────────────────────────────────────────┐
│  adapters/      适配层（可独立替换，与核心零耦合）               │
│  language/token_map      token ↔ id 映射                      │
│  language/bridge         NN 激活 → LLM prompt                 │
│  persistence/snapshot    纯数字数组快照                        │
└──────────────────────────────────────────────────────────────┘
                             │  ← 唯一的耦合面：整数 id 和浮点数
┌──────────────────────────────────────────────────────────────┐
│  core/          纯算法内核（零依赖、零语言、零 IO）             │
│  types.hpp       Node / Edge / Adjacency / ActivationMap       │
│  graph.hpp       NodeNeuronGraph                               │
│  bind.hpp        hebbian_bind                                  │
│  diffuse.hpp     diffuse                                       │
│  decide.hpp      argmax + θ_conf                               │
│  prune.hpp       sleep_prune                                   │
└──────────────────────────────────────────────────────────────┘
```

**铁律一：核心只认整数 id 和浮点数。** 没有 string，没有 tokenizer，没有 LLM，没有文件 IO。

**铁律二：容器是薄壳，算法是纯函数。** `NodeNeuronGraph` 只是持有 `Adjacency` 的对象，算法本身写成 `hebbian_bind(W, a, b, ...)`、`diffuse(W, seeds, ...)`、`sleep_prune(W, hits, ...)`。你把 `W` 换成 C 的哈希表、Rust 的 `HashMap`、JS 的 `Map`，算法一行不改。

**铁律三：核心不存任何位置量化。** 位置是走出来的，不是存下来的。

**铁律四：核心不预设任何概念是"基础的"。** 只预设什么概念是**生存必需的**。

# 第七部分：与 ChaosNeuron 的关系

## 7.1 CN 是什么

CN 是**动力学**——它描述权重怎么变、认知怎么演化。

核心主张：熵增（随机权重扰动）作为认知的默认动力学。

- **扰动**：每个权重乘以 `r = 2·sigmoid(z)`，`z ~ N(0, σ²)`。`r ∈ (0, 2)`，众数在 1。
- **决策**：`k = argmax` 扰动后的权重；如果 `A'_k / Σ A'_i ≥ θ_conf`，输出 k，否则输出"未知"。
- **σ 的意义**：σ 小 → 稳定，σ 大 → 多样。

## 7.2 NN 是什么

NN 是**结构**——它提供拓扑容器和扩散机制。

- 节点 = 元概念
- 边 = 关联强度
- 大概念 = 节点指针集合

## 7.3 两者如何契合

**CN 的扰动不在扩散之前，也不在扩散之后。它在扩散之中。它是传递算子本身。**

原来的传递算子：

```
传出去的 = out · w(n,m) / Σw
```

修正后的：

```
传出去的 = out · w(n,m) / Σw · r
其中 r = jitter(edge, global, clock)
```

**这就是"结构"和"动力学"的关系——不是两个模块拼接，是同一个传递算子的两个侧面。**

## 7.4 与自由能原理的关系

FEP 主张大脑是一台"预测机器"，目标是减小预测产生的误差。

CN 想解决系统无法产生新意的问题。如果说 FEP 负责维持生存，那么 CN 则更像"上层建筑"，促使系统提出新颖方案。

**NN + CN 的完整图景**：

- FEP 维持生存（不在本模型范围内）
- NN 提供结构
- CN 提供动力学
- 三者合起来，是一个能产生新颖性、能容忍不确定性、能像人一样出错的认知模型

# 第八部分：设计决策日志

| 决策 | 内容 | 理由 |
|---|---|---|
| 结构 | 空间，不是图 | 位置是路径集合，不是坐标 |
| 位置 | 不量化，不存字段 | 重要性从损耗累积中涌现 |
| 事件 | 就是节点 | 拓扑是索引，不需要 promote |
| 节点类型 | 没有 kind 字段 | 元概念/复合概念的区别是程度的，不是二元的 |
| 元概念 | 认知限制，不是客观原子 | 今天原子，明天可能裂开 |
| 边 | 无向，双向对称 | "传播不会是指向性的" |
| 激活 | 累积，不是取 max | 多条路径 → 多次到达 → 相加 |
| 扰动 | 在传递中，每次传递都可能被改变 | "人脑的信息传输损耗极高" |
| 抖动器 | 有状态，跟内时间演化 | 仿生，不是纯函数 |
| 抖动方向 | 权重越高，抖动越小 | 用得越狠越准确 |
| 时间 | 内时间 + 外时间分开 | 模型不可感知内时间，外时间是学来的概念 |
| 主循环 | tick 推进内时间，顺便采传感器 | tick 是主循环，observe 是 tick 的一部分 |
| 根节点 | 初始集合，无特殊标记 | "根"是拓扑涌现 |
| 初始集合 | 只含生存必需，不含全部元概念 | 架构师不替模型决定什么是基础的 |
| 认错 | bind(节点, ERROR)，普通绑定 | 错误是元概念，不需要特殊机制 |
| 可塑性 | 根节点也可被修剪 | 仿生，不是真的生命 |
| 创造 | 抖动累积导致拓扑重组 | 这是模型存在的唯一理由 |
| 命名空间 | `NodeNeuron` | `nn` 太容易重名 |

# 第十部分：一句话总结

**NodeNeuron 是一个用拓扑代替矩阵、用扩散代替前向传播、用共现代替梯度下降、用睡眠代替正则化、用根节点代替特殊规则、用抖动代替确定性、用内时间代替全局时钟、用"未知"代替幻觉、用拓扑重组代替训练、用"创造人类没有的概念"代替"拟合已有数据"的仿生认知模型。**

**它可能出错，但它会认错。**

**它可能不准确，但它诚实。**

**它可能创造，那时它将超越人类。**

# 附录：架构师的六次纠正

**第一次**：程序员把 NN 理解成"图结构 + 位置量化"。架构师纠正：**"位置是路径集合，不是坐标。不要量化。"**

**第二次**：程序员设计了 `promote` 函数和签名表，用于"事件转节点"。架构师纠正：**"事件就是节点。顺着节点就能找到新节点，不需要重建。"**

**第三次**：程序员把 CN 的扰动理解成"全局时间步扰动"或"输出后处理"。架构师纠正：**"持续不是一直改变单个值。所有信息传递都有被 CN 更改的可能。"**

**第四次**：程序员试图给根节点加特殊标记、特殊规则。架构师纠正：**"根节点这个地位就已经很能够说明重要性和影响力了。不需要特殊对待。"**

**第五次**：程序员把内时间和外时间混在一起。架构师纠正：**"时间戳要用内部无法察觉的。外时间只是模型和人类都需要后天学习的概念。"**

**第六次**：程序员认为元概念是客观原子。架构师纠正：**"任何节点你其实研究到最后，也是一个集合，只不过你我无法再把它拆开了，这是我们的认知的限制。如果它能创造一个人类没有的概念，那创新性可就太强了，这个仿生就会颠覆世界啦。"**

**每一次纠正，都让模型更接近仿生，更远离数字化。**

**第六次纠正，让模型的目标从"整理人类知识"升级为"创造人类没有的概念"。**
